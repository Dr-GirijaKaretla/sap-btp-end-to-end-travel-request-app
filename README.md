## 📘 Overview
This repository contains my **end‑to‑end SAP BTP learning project**, built entirely using **cloud‑only tools** and optimized for the **SAP Free Tier**.  
The goal is to demonstrate real‑world SAP BTP development across UI, backend, database, security, deployment, and multi‑environment architecture.

---

## 🧱 Project Structure

| Folder | Purpose |
|--------|----------|
| **backend/** | CAP project (Node.js, CDS models, services) |
| **frontend/** | SAP Build Apps exported project |
| **config/** | BTP configuration artifacts (destinations, role collections, manifests) |
| **docs/** | Documentation (architecture, progress, deployment, schema, UI design) |
| **diagrams/** | Architecture diagrams (system, landscape, data model) |
| **tests/** | Optional test automation (API and UI tests) |
